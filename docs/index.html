Jezero Crater Surface System // Sol 1420 Online

Next-Generation Martian Surface Navigation & Cartography

Dalil-Mars is an autonomous EVA navigation and ground control system engineered for the rugged terrain of Jezero Crater, Mars. Integrating high-resolution orbital CTX stereo DTMs, ESA HRSC imagery, slope gradients, and obstacle barrier costmaps for precision surface traverses.
